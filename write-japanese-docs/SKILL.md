# 読みやすい日本語文書を書く

## 最初に書き手と読み手を固定する

文書へ手を入れる前に、誰が誰に向け、どの立場から何を伝える文書かを一文で言える状態にする。
書き手は文書上の発信主体、読み手はその文書を実際に読む人とする。
指定がなければ、書き手はユーザーとする。
既存文書に別の発信主体が示されている場合は、その主体を優先する。
執筆を代行するCodexを書き手にせず、会話相手という理由だけでユーザーを読み手にしない。
書き手の立場、読み手の前提知識、読後に求める判断または行動から、語調と説明範囲を決める。
この関係を途中で変えない。
既存資料から確定できず、選択によって内容が大きく変わる場合は、ユーザーへ確認する。

## 変更範囲と根拠を決める

依頼と既存文書から、新規作成、内容追加、改訂のどれを行うか決める。
同じ読み手と用途を扱う既存箇所があれば、そこを改訂する。
既存文書と役割または読む時点が異なる場合だけ、新しい文書を作る。
分量、形式、非対象範囲など、ユーザーが示した制約を守る。
執筆前に、対象文書、直接参照される文書、同じ読み手や主題を扱う文書、リポジトリの規則、記述する事実の根拠を確認する。

## 文書を作る

[日本語文書の執筆規範](references/japanese-writing-rules.md)を全文に適用する。
既存の用語、構成、情報の置き場所を尊重し、同じ説明を複製しない。
確認できない事実は断定せず、未確認であることを示す。

## 検証して報告する

断定した事実、リンク、パス、コマンド、数値、固有名詞を根拠と照合する。
書き手と読み手の関係、読み手の前提知識、文書の目的、読後の判断または行動が、本文全体で一致していることを確認する。
リポジトリに文書検査があれば実行する。
専用の検査がない場合は、差分とローカルリンクを確認する。
変更した文書、根拠と照合した事項、検証結果、未確認事項を簡潔に報告する。
