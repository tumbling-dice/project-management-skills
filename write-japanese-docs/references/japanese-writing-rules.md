# 日本語文書の執筆規範

書き手と読み手の関係、文書の目的、読後に求める判断または行動を基準に、構成と表現を決める。

## 前提知識の依存順を守る

各文は、想定読者の前提知識として定めた概念か、それ以前に説明した概念だけに依存させる。
対象外の範囲、例外、代替先を示す前に、対象と基準となる原則を説明する。

## 必要な情報を選ぶ

- 読み手の判断または行動に必要な情報だけを残す
- 結論や操作と、その根拠、条件、例外を近くに置く
- 確認済みの事実、推測、決定、提案を区別する
- 未確認の事項は状態を明記し、根拠のない因果や断定を加えない

## 情報の関係を構成で示す

- 見出しから、その節にある情報を予測できるようにする
- 一つの段落では一つの話題を扱い、理由や因果は段落でつなぐ
- 並列事項と手順には箇条書き、同じ条件で比較する事項には表を使う
- 例外と結果の見方は、対応する原則や操作の近くに置く
- 既存の構成で目的を満たせる場合は、その構成を保つ

## 具体的に書く

- 実行者、対象、条件が曖昧になる場合は省略しない
- 読み手が行う手順は読み手への指示として書き、開始位置、対象、操作、結果の見方を示す
- 「ルート」など基準を複数に解釈できる位置表現は、何を基準にするか明示する
- 抽象的な評価を、事実、理由、条件、比較対象へ置き換える
- 用語と表記を統一し、読み手が知らない用語は初出時に説明する
- 各文で情報を増やし、重複や執筆過程の実況を残さない
- 文の長さや接続表現を機械的に揃えず、前後の関係が誤読されない形にする

## 推敲する

冒頭から読み直し、次を確認する。

1. 読み手が必要な情報を見つけ、結論と根拠の関係を読める
2. 主語、指示語、条件、因果の参照先が一通りに定まる
3. 同じ定義、注意、結論を繰り返していない
4. 問い、仮の値、不要な案内が残っていない
5. 文書全体で用語、事実関係、書き手の立場が一致している
