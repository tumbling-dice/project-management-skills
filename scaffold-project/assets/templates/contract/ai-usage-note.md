# AI利用メモ

## 目的

AIコーディングエージェントへ渡してよい情報、任せない判断、扱ってよい環境を定義する。

## AIに渡してはいけない情報

- APIキー、パスワード、秘密鍵、token
- 本番DB接続情報
- マスキングしていない顧客データ
- 本番ログの生データ

## AIに任せない判断

- 本番デプロイ
- 本番DB操作
- 顧客通知
- merge / release
- risk acceptance
- security / privacyの最終判断

## 扱ってよい環境

- 要確認

## 扱ってはいけない環境

- 本番環境
- 本番DB
- 要確認

## 更新タイミング

- 禁止情報や扱える環境が変わったとき。
- 同じ注意を繰り返しプロンプトに書いたとき。
