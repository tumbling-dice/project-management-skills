# Reviewable Gate

Reviewable Gateは、レビューに進めてよい差分かどうかの入口条件です。

テストが落ちている差分、buildできない差分、検証結果が不明な差分はレビュー対象ではなく作業途中として扱う。

## 条件

| 条件 | 確認内容 |
| --- | --- |
| 1. コンパイルできる | buildまたは同等の検証が成功している |
| 2. 対応するテストがある | 変更対象に対応する単体テストを追加または更新している |
| 3. 関連テストが通っている | 対象機能に関係するテストが成功している |
| 4. テストを弱めていない | skip、削除、assert緩和で通していない |
| 5. 検証コマンドが記録されている | 実行コマンドと結果を変更説明に書いている |
| 6. 未実行検証が明示されている | 未実行の理由とリスクが書かれている |
| 7. 権限・個人情報・ログ影響を見た | 認証、認可、tenant、PII、token、secretログの影響を確認している |

## 例外扱い

既存テストの既知不具合などで全体テストが落ちる場合でも、次を記録する。

- 今回差分が原因ではない根拠
- 対象機能に関係するテスト結果
- 失敗ログ
- 影響範囲
- リスク
- 人間によるレビュー開始承認
