# PJ Charterの作成手順

`docs/project/pj-charter.md` を作るときに使う。

## 目的

PJ Charterは、実装前にPJの意図と最初の範囲を見える形にするための文書です。AIエージェントが目的を勝手に作ったり、範囲を広げたりすることを防ぎます。

## 必須セクション

- `目的`
- `背景`
- `対象ユーザー`
- `解く課題`
- `MVP範囲`
- `非対象範囲`
- `成功条件`
- `制約`
- `確定事項`
- `仮説`
- `未決事項`
- `人間が判断する点`

## ルール

- ユーザーが示した業務意図を判断の起点にする。
- 推測した業務ルールは `仮説` に置く。
- 不明な判断は `未決事項` または `要確認` に置く。
- 非対象範囲は、誤って実装されない程度に具体的に書く。
- 成功条件は曖昧な評価ではなく、「role Xがstagingでflow Yを完了できる」のように観測可能な形にする。
