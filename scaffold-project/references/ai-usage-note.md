# AI利用メモの作成手順

`docs/ai/ai-usage-note.md`、または同等のPJ内暫定ルールメモを作るときに使う。

## 目的

この文書では、PJ初期にAIエージェントへ任せてよいこと、任せないこと、promptや生成文書に入れてはいけない情報を定義する。

## 必須セクション

- `目的`
- `AIに任せてよいこと`
- `AIに任せないこと`
- `入力してはいけない情報`
- `扱ってよい環境`
- `扱ってはいけない環境`
- `実装前に必要な確認`
- `レビュー前に必要な確認`
- `本番操作に関する禁止事項`
- `更新タイミング`

## ルール

- AI出力は候補であり、最終判断ではないと明記する。
- 本番deploy、本番DB操作、顧客通知、merge判断、release判断は人間の管理下に置く。
- secrets、token、credential、本番ログの生データ、マスキングしていない顧客個人情報を禁止する。
- 未確認のルールは `要確認` として残す。
