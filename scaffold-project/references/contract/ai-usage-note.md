# AI利用メモの作成手順

`docs/contract/ai-usage-note.md`、または同等のPJ内暫定ルールメモを作るときに使う。

## 目的

この文書では、PJ初期にAIエージェントへ渡してよい情報、任せない判断、扱ってよい環境を定義する。

## 必須セクション

- `目的`
- `入力してはいけない情報`
- `AIに任せない判断`
- `扱ってよい環境`
- `扱ってはいけない環境`
- `更新タイミング`

## ルール

- 本番deploy、本番DB操作、顧客通知、merge判断、release判断は人間の管理下に置く。
- secrets、token、credential、本番ログの生データ、マスキングしていない顧客個人情報を禁止する。
- 未確認のルールは `要確認` として残す。
